# 训练数据导入

训练记录按来源和账号保存。最近日期范围从旧到新读取，历史从新到旧读取；接口返回达到上限时递归拆分日期范围。每个低于上限的完整子区间与其检查点在同一个事务中保存，失败或取消后重试会从检查点继续。最近记录重读上次完成的最后一天，以覆盖当天后续新增的记录；单日仍达到上限时报告未完成，不越过该日。

高驰开始时间按 Unix 秒解析，接受从 Unix 纪元开始、且在任意合法时区展示时不超过 9999 年的时间，不要求与来源日期相同；越界值和毫秒误传会使导入失败。展示日期使用手机当前时区，回到前台时重新读取时区。训练子类型使用稳定的持久化代码，兼容现有 v6 记录。

导入进度以 `TrainingImportProgress` 的阶段和日期范围表示，展示层负责中文文案。训练子类型使用稳定 code 而不是枚举名称持久化；本地记录按来源和账号隔离，解绑隐藏当前缓存，重连同一账号可继续使用。

周/月统计使用与记录列表相同的日期转换。`TrainingStatisticsIndex` 按自然周期和运动大类一次聚合本地记录，周期点选从索引读取，不重复扫描全部历史；记录、手机时区、日期或偏好变化时重建索引。汇总内部以米计算，展示时才换算为公里，综合系数不会修改原始记录。

`TrainingUiState.historyComplete` 来自现有导入检查点。首次导入中断时保留不完整状态；完成后才允许没有记录的周期表示为零。更新进行中或失败、任一期缺失距离时，不显示增长率。统计界面按缓存记录展示，最新数据仍由用户点击「更新」获取。

训练偏好与高驰账号独立，保存于本机应用私有文件。保存失败保留原偏好，成功后发布新值供所有统计重算；偏好增加不修改 Room v6 schema。
