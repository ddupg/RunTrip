# 比赛与配速工具行为

- 配速计算的自定义距离须大于 0 且不超过 1000 公里。该上限覆盖常见长距离赛事，同时将每 5 公里的累计分段限制在最多 200 行；输入和计算入口使用相同边界。
- 首页、详情和编辑表单加载比赛失败时显示错误和重试；空列表与找不到记录分别显示为空状态和未找到。重试重新读取本地数据。
- 首页快捷状态面板打开后，读取失败仍保留面板和更新结果；重新读取成功时使用最新记录，记录已不存在则关闭面板。
- 首页快捷状态保存期间保持面板打开，失败后显示错误并可重新选择状态重试。
- 新增和编辑比赛保存期间禁止修改草稿、重复保存和返回或取消。保存失败后保留草稿，允许继续修改和重试；成功后按原有流程关闭页面。

- 首页筛选和快捷状态面板位于 `HomeSheets.kt`；配速完赛时间面板与滚轮位于 `FinishTimePickerSheet.kt`。页面负责连接状态和用户动作，面板负责各自的展示与临时选择。
