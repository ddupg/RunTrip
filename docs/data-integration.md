# 数据接入

用户操作与统计公式见[产品约定](product.md)，本篇维护高驰连接、接口解析及本地导入的实现约束。

## 授权与凭据

- 使用官方跨设备浏览器授权流程。OAuth `/userinfo` 实测只提供 `sub`，昵称从 MCP `queryUserInfo` 的 `Nickname` 读取。
- 凭据使用 v1 加密封套，保存在应用私有的非备份目录，不写入 Room 或日志。读取失败显示错误并允许确认重置，只删除该来源连接文件，不自动覆盖损坏文件或删除训练记录。
- userinfo 或 MCP 返回 HTTP 401 时，用 refresh token 续期并重试一次；每次操作最多续期一次，再次拒绝报错但保留凭据。只有续期返回 `invalid_grant` 才清除连接并要求重新授权。
- 领取会话、使用 ticket 和交换 code 前持久化已开始标记；响应丢失后不自动重放一次性凭据，尚未开始的阶段可继续。不能恢复时取消连接并重新授权。
- 领取 ticket、交换 code、轮换 refresh token 及保存结果作为不可取消的有限网络阶段，阶段间检查取消。网络中断或进程退出仍可能丢失已消费凭据的结果，需要重新授权。
- 连接与读取超时分别为 15 秒，每次请求另有 30 秒总期限。取消训练读取时尝试断开连接并释放等待协程，底层 I/O 结束仍受平台与超时影响。

## 接口解析

- 受支持活动编码：跑步 `100/101/102/103`，骑行 `200/201/202/203/204/205/299`，游泳 `300/301`；以运动工具定义为依据，不复用训练课程编码。
- 列表与详情实测无 `structuredContent`；`content[].text` 为 JSON 编码字符串，解码后仍是格式化文本。严格解析，未知格式、数量不符、重复记录或工具错误均终止该次解析，不能静默少算。
- 距离可能为 `km` 或 `m`，时长为 `MM:SS` 或 `H:MM:SS`，使用 Workout Time / Duration，不按起止时间差计算。公里文本样本仅保留两位小数，累计结果不能宣称为原始米级精度。
- 无距离记录保留缺失值；泳池记录的详情也可能无距离。泳池列表曾将配速单位标成 `/km`，详情为 `/100m`，不能直接将列表配速用于泳池展示。
- 开始时间按 Unix 秒解析，接受纪元起、在任意合法时区展示均不超过 9999 年的时间，不要求与来源日期一致。越界值和毫秒误传使导入失败；展示使用手机当前时区，回到前台重新读取。

## 导入与本地计算

- 记录和检查点按来源、账号隔离，按来源记录标识去重更新；训练子类型使用稳定 code，兼容 v6 记录，不持久化枚举名称。
- 最近区间从上次完成日期与最近 14 个自然日（含今天）的起点中取较早者，首次以当年元旦代替上次完成日期。最近区间从旧到新读取，历史从其起点前一天向 1970 年逆序读取，不因空区间终止。
- 返回数量达到上限时递归拆分日期范围；每个低于上限的完整子区间与检查点在同一事务保存。失败或取消后按检查点及回查规则继续；单日仍达上限时报告未完成，不越过该日。
- 周/月统计按自然周期与运动大类一次聚合，点选周期不重复扫描全部历史；记录、时区、日期或偏好变化时重建索引。内部以米汇总，展示时换算。
- 统计完整性来自全局导入检查点；不根据空窗口推断零训练量。缺失距离及更新状态对显示的影响由产品约定统一定义。
- 偏好与高驰账号独立，存于本机应用私有文件，不修改 Room v6 schema。保存失败保留原值，成功后发布新值供所有统计重算。

## 验证边界

以下为 2026-11-01 接入验证留下的结论，不代表后续版本已完成真机验收：

- 手机浏览器授权与令牌领取、令牌刷新、三类运动样本读取及一个完整月份的次数和距离核对已通过；该月时长未人工核对，部分骑行子类型仅有工具定义、缺少真实样本。
- 1970 年起分五年窗口及当年窗口查询成功，未达到请求的 `limit=1000`；全历史未与高驰 App 逐条核对。单次全历史查询超时不证明服务端有固定五年上限；更大数据量的最高 limit、截断及服务端删除行为仍缺实测。
- Android 真机安装、浏览器返回后的授权恢复及 Android Keystore 实机验收尚未完成，模拟环境和跨设备授权不能替代。
