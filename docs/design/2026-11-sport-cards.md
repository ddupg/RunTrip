# 竞技卡片 UI 改造

采用用户选定的第二种风格：黑白中性色、少量运动黄绿、号码布 29、紧凑卡片。它替代首轮已搁置的竞速蓝提案。

## 页面与交互

| 区域 | 实现 |
| --- | --- |
| 首页 | 固定小标题与添加入口；轻量文字切换；紧凑月份与赛事卡片；状态独立点击 |
| 添加比赛 | 可滚动完整底部表单，顶部保存；包含日期选择器 |
| 编辑比赛 | 独立页面，与新增复用所有字段和校验 |
| 详情 | 移除重复的大号日期；赛事、行程、住宿、备注分组 |
| 工具 | 独立顶层页；配速计算仍是独立完整页面 |
| 主题与图标 | 固定深色主题（不跟随系统，浅色保留为设计预览）、统一控件颜色和圆角；普通 / 自适应 / 单色启动图标统一为号码布 29 |

## 表单保留清单

- 名称、城市、日期（支持历史日期）、运动大类、比赛项目、参赛状态。
- 路跑：中国田协等级、World Athletics Label。
- 越野：比赛距离、累计爬升；铁三：原有项目选择。
- 出行路程、酒店预订状态、酒店名称、预订平台、总价、酒店备注、比赛备注。
- 切换大类的草稿暂存、必填 / 数值校验、失败重试、加载与保存状态。
- 筛选的确认 / 取消语义、快速修改状态、详情编辑与删除、配速及分段计算均保留。

本次不改变数据库、比赛状态含义或离线产品边界。未开始仅按日期分段，不表示将参加该赛事。

## 验证

执行 `./gradlew test lint assembleDebug`。新增表单会话测试覆盖取消、连续添加、保存中关闭保护，并在完整字段保存测试中校验日期与酒店备注等信息。另做临时的 Robolectric Android 16 原生渲染检查，4 项通过：

- 黑白首页在 393 × 852 dp 显示 6 场常规比赛，状态点击独立于详情。
- 添加弹框展示日期，滚动可访问所有原有公共字段。
- 实际应用导航到工具 / 配速页；选择 29 日、新增保存、查询数据库并进入详情。
- 1.6 倍字号下日期完整，状态移至卡片内容下方。

截图与临时检查源码、XML 结果保存在 `app/build/reports/redesign/`。这是本地渲染，使用测试数据，不属于设备截图。临时检查仅为 Android 16 渲染使用本机已有的较新 Java 运行时；检查结束后恢复构建配置，项目仍按原有 JDK 17 环境运行单元测试，不新增依赖。

设备验收仍需覆盖真实系统字号设置、键盘弹出、底部手势返回、日期输入与真实触控；本机无连接设备时不将这些记为通过。

本次全量结果：原 JDK 17 配置下 `./gradlew test lint assembleDebug` 通过；87 项单元测试无失败，Lint 无错误（18 项配置 / 版本提示），Debug APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。未连接 Android 设备，未执行真机验收。
