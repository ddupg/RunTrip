# 产品范围与体验规范

## 产品定位

RunTrip 是 Android 16 上的个人单机路跑、铁三与越野行程记录及备赛工具应用，用来替代手机记事本，集中管理比赛日期、城市、项目、参赛状态、赛事等级、路程距离和酒店信息，并承载轻量跑马工具。

所有数据仅保存在手机本地。未经明确确认，不加入账号、后端、联网、云同步、通知或多端能力。

## 首版范围

- 按月份浏览未开始和历史赛事；记录不等于确认参赛
- 按参赛状态和比赛项目组合筛选，并在列表中快速更新状态；更新失败时保留面板并允许重试
- 首页采用紧凑赛事卡片；上滑时月份、分段切换和筛选随列表滚动，顶部保留 RunTrip 与添加入口
- 新增、编辑、查看和删除比赛记录；新增使用可滚动的完整底部表单，编辑保留独立页面
- 为路跑赛事记录中国田协等级与 World Athletics Label
- 记录酒店预订状态、酒店、平台、总价和备注
- 通过“比赛”和“工具”两个顶层入口切换行程记录与轻量跑马工具
- 根据 5 公里、10 公里、半马、全马或自定义距离及完赛时间，计算平均配速和累计分段时间
- 默认固定深色模式，不随系统主题变化

首版不包含账号、云同步、通知、交通安排、数据备份恢复和 Play Store 发布。

## 视觉与无障碍

- UI 使用中文，品牌名固定为 `RunTrip`。
- 采用 Material 3 的紧凑竞技卡片风格，Logo 保留号码布，号码固定为 29；黑白中性色为基础，深色模式使用低饱和黄绿色强调。
- 浅色模式使用纸白底、白色卡片和石墨色交互；深色模式使用近黑底、深灰卡片和黄绿色交互。App 固定使用深色，浅色配色仅供设计预览；启动窗口和系统栏同样使用深色样式。
- 输入焦点、日期选择和其他选中控件使用同一高对比度色系，并通过勾选等非颜色提示表达状态。
- 卡片使用细边框、小圆角和紧凑间距；月份标题与“未开始 / 历史赛事”文字切换弱化处理，不使用大面积实心分段按钮。
- 参赛状态按关注优先级分层：已报名和待抽签使用主题主色紧凑实心标签，已中签使用次级实心标签；待报名使用清晰的无边框“图标 + 文字”，关注中、未中签、已放弃和已完赛弱化显示。
- 首页、详情页和快速更新面板为每种参赛状态显示一致的线性图标；表单和筛选仍使用中性文字控件，避免把选项误认为当前状态。
- 底部导航只在“比赛”和“工具”两个顶层页面显示，内容区高度固定为 64dp，并额外保留系统导航安全区；比赛详情、编辑和具体工具页面不显示底部导航；添加弹框覆盖首页导航。
- 工具首页使用单列卡片，只展示已经可用的工具，不显示不可用的占位项。
- 首页使用统一筛选面板：参赛状态和比赛项目均可多选，同一条件内取并集、不同条件间取交集；未选择的条件不限制结果。
- 月份标题显示该月结果数量；启用筛选时显示总结果数与启用的条件数量，不展示具体选项；分段切换和筛选位于同一行，随列表滚动收起。
- 筛选面板中的修改仅在点击“确定”后生效；关闭、返回、点击遮罩或下滑均放弃未确认的修改，“重置”也需要点击“确定”后才生效。

## 添加与编辑

- 首页右上角添加按钮打开完整底部表单，包含名称、城市、比赛日期、大类、项目、状态、专项字段、出行路程、住宿和比赛备注。
- 新增与编辑复用同一表单、日期选择器和校验逻辑。日期默认今天，可通过日期选择器修改，也可以记录过去的比赛。
- 新增弹框内容可滚动，顶部保存按钮保持可用；字段错误就地展示，保存失败保留草稿供重试。
- 保存中禁止关闭新增弹框和重复保存；保存成功关闭弹框，明确取消则丢弃草稿。再次添加使用新的默认草稿，不继承上一条的日期、错误或保存完成状态。
- 普通字号下，393 × 852 dp 视口以显示至少 6 条常规赛事为布局目标。长名称、越野扩展摘要和系统大字号允许卡片增高；窄屏 / 大字号下状态移至卡片内容下方，不裁切名称来凑条数。
- 赛事主体进入详情，状态保留独立点击动作和至少 48 dp 触控高度。

## 运动大类与比赛项目

- 运动大类分为路跑、铁三和越野跑（简称越野）。路跑项目为全马、半马、10 公里、其他；铁三项目为半标、全标、其他。更长距离的铁三可选其他并填写赛事备注。
- 新建默认路跑半马。先选大类，再选该类项目；首次切换到未填写的路跑或铁三大类时项目为空，保存前必须选择；越野直接填写比赛距离。
- 越野使用自定义比赛距离（公里，必填且大于 0），累计爬升为选填的非负整数米数。比赛距离与出行路程分别保存。列表显示“越野 · 30 km”，填写爬升时附带“爬升 1200 m”；详情展示累计爬升，筛选支持“全部越野”。
- 同一次编辑分别暂存各大类的项目和专属输入，切回时恢复；保存只保留当前大类详情，取消编辑不更改数据。已保存为其他大类后，原大类专属信息不再恢复。
- 比赛名称、城市、日期、参赛状态、出行路程、酒店和赛事备注由各大类共用。赛事等级只出现在路跑表单；铁三目前没有额外专属字段，不展示空区块。
- 首页混合按日期分组，摘要显示“路跑 · 半马”或“铁三 · 半标”。项目筛选按大类分组，支持整组选中或取消，也支持跨大类多选；两类的“其他”分别匹配，不相互混淆。
- 本次不增加主办方、三项距离、成绩和铁三配速工具。

## 配速计算约定

- 配速工具的距离预设与比赛记录的项目分类解耦，不修改或复用 `RaceCategory`。
- 首次进入时距离和完赛时间均为空；离开配速计算页后清空本次输入。
- 自定义距离在当前页面输入，单位固定为公里；完赛时间通过小时、分钟、秒三列滚轮选择。
- 距离和时间均有效后自动更新结果，不增加单独的“计算”按钮。
- 平均配速使用 `4′59″/公里` 格式；分段时间统一使用 `HH:MM:SS` 格式。
- “分段时间”按每 5 公里展示到达该节点的累计时间，最后一行始终展示终点总时间；终点为 5 公里整数倍时不重复显示。

## 数据展示约定

数据库存储稳定的英文 code，中文仅作为 UI 展示文案，不直接持久化为状态或类型值。
