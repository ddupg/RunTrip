# 产品范围与体验规范

## 产品定位

RunTrip 是 Android 16 上的个人单机马拉松行程记录应用，用来替代手机记事本，集中管理比赛日期、城市、项目、参赛状态、赛事等级、路程距离和酒店信息。

所有数据仅保存在手机本地。未经明确确认，不加入账号、后端、联网、云同步、通知或多端能力。

## 首版范围

- 按月份浏览即将到来和历史比赛
- 按参赛状态筛选，并在列表中快速更新状态
- 比赛列表上滑时收起副标题、分段切换和筛选，仅保留 RunTrip 标题
- 新增、编辑、查看和删除比赛记录
- 按具体赛事记录中国田协等级与 World Athletics Label
- 记录酒店预订状态、酒店、平台、总价和备注
- 支持系统浅色与深色模式

首版不包含账号、云同步、通知、交通安排、数据备份恢复和 Play Store 发布。

## 视觉与无障碍

- UI 使用中文，品牌名固定为 `RunTrip`。
- 遵循 Material 3 的号码布风格，荧光黄绿色作为单一品牌强调色。
- 荧光黄绿色只用于具有深色内容的品牌填充组件，以及勾选等小面积强调；不作为浅色背景上的细线或文字。
- 输入焦点、日期选择和其他选中控件使用同一高对比度色系，并通过勾选等非颜色提示表达状态。
- 浅色模式使用深橄榄色承担交互状态；深色模式使用高对比度黄绿色和夜色表面，二者均保持清晰的内容对比。

## 数据展示约定

数据库存储稳定的英文 code，中文仅作为 UI 展示文案，不直接持久化为状态或类型值。
